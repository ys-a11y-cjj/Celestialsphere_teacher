# 天球互動模型

高一基礎地球科學的天球互動模型：太陽與恆星的周日運動、周年運動。可切換天球視角、地平模式、教科書視角與觀察者模式；觀察者模式另有模擬星軌照片的「照片模式」。

**正式版：<https://ys-a11y-cjj.github.io/Celestialsphere_teacher/>**

作者：張淵淑（臺北市立中山女子高級中學）
使用Claude Opus 5協作

## 使用方式

- **線上使用**：用瀏覽器開啟上面的正式版網址。電腦、iPad、iPhone 都可以。
- **離線使用**：下載 `index.html`，直接雙擊開啟。整個模型只有這一個檔案，不需要安裝，也不需要網路。

本模型完全離線運作，不會連線到任何網站，也不會收集或傳送任何資料。
